# Pixelarticons subset

Six original 24×24 SVG paths from [Pixelarticons](https://github.com/halfmage/pixelarticons/tree/c9ecc2da61afde85dbe539025e3d931c6152ad75): plus, minus, chevron-down, close, refresh and info-box (public name `info`). The files are represented as path data in `pixelarticons.ts` and rendered with `currentColor` by `Icon`.
