Dialog accepts `mobilePlacement="bottom"` to present the same dialog as a bottom sheet at viewport widths up to 600px and as a centered window above that width. Content, form state and focus stay in one dialog while resizing. Dialog also reveals its active field after geometry changes so a long form does not leave the focused control hidden behind its footer. The default `center` mode and Drawer side placement remain available.
